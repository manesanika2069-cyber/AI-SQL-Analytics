# AI SQL Analytics

An AI-powered analytics dashboard that converts natural-language questions into SQL queries and executes safe queries on a SQLite sales database.

## Features

- Natural-language questions
- Gemini-powered SQL generation
- SQL safety validation
- SQLite database execution
- Query results
- Interactive visualizations
- SQL explanations
- Query history

## Technology Stack

- Python
- Streamlit
- Google Gemini API
- SQLite
- Pandas
- Plotly

## Example

User question:

> Show total revenue by category

The application generates SQL, validates it, executes it against the sales database, and displays the result with a visualization.
